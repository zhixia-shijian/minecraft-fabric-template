# Minecraft Fabric Template

This repository was created to host a complete Minecraft Fabric mod template.

## Getting started

1. Open the project in IntelliJ IDEA or VS Code.
2. Run `./gradlew build`.
3. Copy the generated jar from `build/libs` into your Minecraft `mods` folder.

## Planned template contents

- Fabric mod bootstrap
- Example item and block
- Item group
- Command example
- Client initializer
- GitHub Actions build workflow
